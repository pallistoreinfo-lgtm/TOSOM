The Other Side of Medicine — Website Rebuild

What we set out to do

Two goals.

Goal 1

Faithful recreation

Rebuild the site so it looks and reads like the same practice — same brand, content, navigation, and structure — without the WordPress and page-builder baggage.

Goal 2

Maintainable by an AI agent

Make every article and page a plain text file an agent (or a person) can edit directly — no page builder, no database, no developer required for routine updates.

What we built

A modern, code-based version of the site.

  • Every article and page is now a simple content file. 45 blog articles, 73 podcast episodes, and 35 pages were pulled from the old site and converted into clean, editable files. To update an article, you change one file — no clicking through a page builder.
  • The look and feel was faithfully recreated — the same blue-and-navy brand, the full navigation menu, the hero, the three-step "Evaluate → Modify → Support" framework, patient case studies, conditions, lab tests, and the $79 consultation call-to-action.
  • Built on a professional component library (shadcn/ui) themed to the practice's brand, so the site is consistent, accessible, and easy to extend.
  • All images were downloaded, optimized, and stored with the site — no longer dependent on the old WordPress host, and lighter/faster than before.
  • The booking (Calendly) and gut-health quiz (JotForm) still work, the podcast streams from its existing host, and the shop continues to link to the existing store.

We also fixed the site's SEO

A search audit of the live site scored it 72/100. The rebuild was the perfect moment to fix the structural problems for free. Here's the before and after.

Issue (old site)BeforeAfter
Page headings Key pages had zero main headings (H1) — a top Google ranking signal was missing entirely. Exactly one keyword-led headline per page. Verified on all 155 pages.
Page titles "Home - THE OTHER SIDE OF MEDICINE" — wasted space, no keywords. "Functional Medicine for Gut Health & Root-Cause Healing" — keyword-led, brand trimmed.
Search descriptions 47 pages had missing or weak descriptions (many just repeated the title). Rewritten with a hook + call-to-action across every article and money page.
Sitemap robots.txt had no sitemap link; the common /sitemap.xml path returned an error. Proper sitemap generated and referenced for search engines.
Author credibility (health/YMYL) Doctor credentials only on the homepage — weak for medical search after Google's Dec 2025 update. Author credentials block + author markup on every article.
Page speed Render-blocking page-builder code; articles weighed 200–220 KB. Static pages with minimal code (~111 KB) — faster on mobile.

How updates work now

This is the payoff: routine changes no longer need a developer or a WordPress login.

  • Add an article: create one content file with a title, summary, and the body. It appears on the site and in the article list automatically, with the author block and search markup already attached.
  • Change the menu, phone number, or a link: edit one settings file — the single source of truth for the whole site.
  • Add a condition page or podcast episode: copy an existing file and fill it in.

An included guide (the project README) walks through each of these step by step.
